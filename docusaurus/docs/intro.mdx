# Spider Sense

Spider Sense met en relation les citoyens et les super-héros :

- un **citoyen** signale un incident depuis son téléphone (bouton SOS ou formulaire détaillé) ;
- les **super-héros** disponibles le voient sur leur carte, le prennent en charge et clôturent l'intervention ;
- les **modérateurs** et **administrateurs** supervisent : incidents, comptes, demandes de statut héros, avis, films, blog et newsletter.

## Espaces de l'application

| URL | Pour qui | Contenu |
|---|---|---|
| `/` | Tout le monde | Site public : présentation, super-héros, vidéothèque, blog |
| `/citoyen` | Citoyens connectés | App mobile : bouton SOS, suivi des signalements, notation des héros |
| `/heros` | Super-héros validés | Centre d'opérations : carte des incidents, profil, réputation, films |
| `/admin` | Modérateurs et admins | Tableau de bord de modération |

## Stack

- **Next.js** : les pages, et une API REST (`app/api/**/route.ts`) que l'interface appelle pour toutes les opérations
- **PostgreSQL** avec **Drizzle ORM** (ou PGlite, une base embarquée, sans Docker)
- **Nodemailer** pour les mails, capturés par **Mailpit** en développement
